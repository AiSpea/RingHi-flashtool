## 0.3.18 已有证据

- Mac 实机两块 RingHi 同时烧录，ML307H 分别约 25 / 27 秒，包含逐板备份、下载和授权；两板 ESP32 最终 MD5 均一致。
- 两板产测、云端登记、最终报告上传均通过，整板约 99 / 100 秒。一次小样本不能代表量产长期稳定性。

- 本地 201 项软件测试、Windows 84 项针对性测试与启动检查通过。Windows 0.3.18 未重新执行实物烧录。
