连接与测试准备
Windows 优先
ML307H 运行模式可选择系统 AT 串口；下载模式使用 USB 3563:1000 的接口 0，须能由 WinUSB 访问。现有归芯驱动是否兼容，需要接入实物确认。工具不会自动替换电脑驱动。
macOS 可使用 ML307H 原生 USB AT 接口。运行模式为 3563:2000、AT 接口 4。首次切换下载模式时，按提示选择下载设备。
一次完成双芯片烧录
  1. 连接同一块 RingHi 的 ML307H 和 ESP32 下载接口，关闭占用端口的串口助手或官方工具。
  2. 选择 ML307H PKG、备份总目录并连接设备；需要激活时登录官方账号，选项目并开启自动激活。
  3. 选择 ESP32 固件，核对地址和芯片型号后连接 ESP32。
  4. 点击“开始双芯片烧录”。ML307H 成功后自动继续 ESP32；失败会停止后续步骤。
  5. 检查本机记录，再验证 RingHi 启动、联网和实际功能。批量页面支持烧录后自动产测；本单板手动页面只执行烧录。
备份与恢复
ML307H 自动创建独立备份目录，保护校准及工厂数据。中断后用原 PKG、原板和原备份恢复；激活结果不确定时先核对官方平台，禁止重复领取。
ESP32 只擦除待写地址覆盖的扇区，不提供全片擦除入口；写入地址仍可能覆盖设备配置，请核对固件布局。
当前验证范围
软件测试和模拟协议不能证明真实烧录、激活或整板运行成功。真实验收需匹配的 RingHi 固件、实物板、下载驱动及有权限的官方账号。
