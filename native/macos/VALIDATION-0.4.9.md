# RingHi Mac 0.4.9 自动更新验证

## 范围

新增原生 Mac 自动更新；不修改 Windows、固件、授权协议或产测规则。独立 `mac-v` 发布使用 ZIP + SHA256SUMS，PKG 保留用于首次安装及 0.4.8 之前的引导升级。保持原 bundle ID 和应用路径。

## 软件验证

- 原生 arm64/macOS 13 构建及严格代码签名校验通过。
- 自检 297 项：版本排序、Windows/预发布过滤、资产来源、校验清单、ZIP 路径与链接、下载上限/取消/超时、替换失败回滚、重启回执、CSV 保存失败不退出、任务与登录期间锁定升级，以及原有烧录/产测/恢复回归。
- 真实生成的 ZIP 通过预解压安全检查。
- 隔离 UI 验证：左下角显示更新提示，任务执行时禁用；关闭取消后任务保持，确认关闭后 CSV 保存一条中断记录。

## 本机覆盖验证

- 对已有 `/Applications/RingHi Flasher.app` 使用同一更新助手执行等待旧进程退出、复制候选、原位替换及自动重新打开。
- 新窗口显示 0.4.9，原授权账号登录成功，原项目、固件路径和配置仍在。
- 原 `native-macos` 的 27 个数据文件逐一 SHA-256 对比无变化。更新不读写钥匙串凭据内容，不替换外部 CSV 或备份目录。
- 0.4.8 没有入口，本次由测试驱动引导助手；不能把此次引导升级描述为从 0.4.8 的界面点击自动更新。
- 本轮没有操作实物烧录。管理员权限分支保留系统授权弹窗，本机目录可写，未实测受保护目录升级。

## 发布约束

发布前核对 PKG/ZIP/校验清单，保持 Mac Release 的 `latest=false`。自动检查通过公开匿名 HTTPS，仅允许指定 GitHub 资产跳转；仍须真实网络可达。
当前仍为 ad-hoc 签名，无 Developer ID 公证；系统钥匙串可能要求再次允许，不能保证所有新电脑静默授权。
