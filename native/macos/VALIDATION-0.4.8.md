# macOS 0.4.8 连接复用与身份恢复

## 行为

- 官方请求复用共享 URLSession 连接池；账号快照共享池，每个请求独立保存响应、错误和取消状态。单板取消只取消其任务，不能使其他板的会话失效。保持直连、证书验证、禁止重定向和响应大小限制，不携带跨请求 Cookie；已收到的激活回执在取消时仍保留。
- 同 MAC 的旧卡槽 IMEI 别名，通过后来已验证的身份、相同 UID/原固件、原始备份及完成的授权相互印证后解析；旧记录不删除。真实 ROM UID 在新备份与分区写入前再次核验。
- 下载模式支持已验证任务重烧和尚未写入任务恢复。保存 previousBackup 和 verifiedAt。分区写入/备份阶段的任意中断恢复仍未开放，不能理解为完全等同 Windows 的恢复覆盖范围。
- 同步此前产品类型、双 SIM 可选卡槽判定、主卡槽身份、授权恢复及下拉框滚轮保护。
