# 原生批次授权准备 0.4.4 — 2026-10-26

## 行为变化

旧逻辑登录只获取会话和项目列表，每块板在写前再次请求项目公共材料（getkey/getprivatekey），网络失败会使已识别的板卡停在 0%。新逻辑在开启批次时准备一次，成功后才允许开启接收；同批次各板从内存复制材料，MAC/IMEI 核对完成即可开始双芯写入。每台设备仍在写后按自己的产品码请求激活码并上报，未共享或缓存设备激活码。

公共材料绑定账号及项目，只存内存，不写进批次 JSON、CSV、日志或备份；取消准备、取消 CSV、新批次替换或退出时释放。各设备副本独立。暂停接收后继续同一批次可复用；重新开启批次重新准备。

仅公共材料获取可对明确的临时网络/HTTP 408/502/503/504 失败尝试最多两次，间隔一秒；登录失效、证书信任失败、业务拒绝及材料格式错误不自动重试。设备激活码、第三方激活码和上报仍不自动重放。未降低 TLS 校验、未修改驱动、未绕过授权或备份。
