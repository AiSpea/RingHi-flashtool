# Windows 0.5.8 重烧与授权恢复验证

基线：RingHi-flashtool origin/main c56f88be；在现有产品类型修改上继续开发，保留双空 SIM 卡槽 / SIM + eSIM 的选择与 CSV。用户明确确认同设备同授权可重复申请而不重复领取，要求工具不因旧的未确认记录永久阻塞。本次按此业务约定实现恢复；没有独立验证官方服务的额度幂等语义。

## 行为

- RingHi 运行固件先确认主卡槽 0；产测遗留槽 1 时恢复并重新读身份，再查询 intent/授权记录。stock/空模块原身份路径不增加切槽命令。切槽、激活卡槽和读回均须成功，不忽略卡槽失败。
- 同设备、同项目、原固件和原备份的未完成激活，在新任务中恢复；运行和下载模式均可恢复。下载器读取实际 UID 后才允许激活，已写固件不重复擦写。已完成写入的设备仍支持正常新批次重烧。
- 旧授权 ledger 和已有 DPAPI 回执先归档；账号、项目/UID 不匹配或备份损坏仍阻止误恢复。新任务允许重新尝试，不把未知结果改成成功，也没有引入无限网络重试。
