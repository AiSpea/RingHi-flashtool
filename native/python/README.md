# RingHi Windows 原生工作台 0.5.6

Python + PySide6 / Qt Widgets 完整实现。无浏览器内核，不调用 C# 程序或 DLL。
ESP32 使用校验 SHA-256 的乐鑫官方 esptool 5.6.0；ML307 下载、备份、授权、串口拓扑和调度由 Python 实现。

## 0.5.6 安装与在线更新

- 分发 `RingHi-Setup-0.5.6-win-x64.exe`，安装到当前用户的固定目录，生成 RingHi 快捷方式；同一安装标识原位升级。
- 首页左下角自动检查更新。空闲时点击更新，下载并验证 SHA-256，保存 CSV 和配置后退出安装，完成后自动打开，无需重启电脑。
- 接收或执行烧录时不能更新；下载期间锁定新批次，失败恢复操作。安装器不强制终止烧录进程。
- 数据继续保存在原用户目录，卸载不删除账号、CSV 和备份。更新助手启动失败时应用保持打开。
- 构建安装包使用 Inno Setup：先 `build.ps1`，再 `installer/build-installer.ps1`。Release 需包含 EXE、兼容旧版的 ZIP 和 SHA256SUMS.txt；上传完成后才发布 Release。

## 0.5.5 识别与网络等待
- 插入后先读取 ESP32 MAC、ML307 型号与 IMEI，再处理联网授权，网络等待不遮蔽本地识别结果。
- 授权登录、项目查询、激活、更新检查及下载全部固定直连，忽略系统代理和代理环境变量；也不再用首页连通性作为接口调用的前置条件。
- 本批次刚准备好的授权短期复用；可恢复的网络中断显示等待并自动继续，可随时取消或拔出。

## 0.5.4 授权连接恢复
- 每个工作线程复用 HTTPS 连接，直连优先；联网状态和自动恢复进度直接显示。
- 区分连接建立失败与请求已发出后的响应中断；前者安全恢复，后者保留现场核对，避免重复领取。
- 确认未发送的激活请求可在后续批次补激活，复用原备份、核验 UID，不重复写入 ML307 固件。
- 已收到的授权回执使用本机 DPAPI 加密保存，诊断日志仅记录请求阶段、耗时和错误类别。

## 0.5.3 首次识别与授权联网
- ESP32 USB 复位导致串口句柄失效时，按原 Hub 和芯片重新识别；读取 MAC 后的写入和校验不再重复复位。
- 官方授权服务优先直连；仅连接建立超时且请求未发送时重试，延长激活响应等待时间。
- 保留未确认激活请求的保护，并记录不含密钥的网络失败类别；不自动重复未知结果的激活请求。

## 0.5.2 滚动与批次保存

设备表格按实际行数展开，无内部横向或纵向滚动条，滚轮统一控制页面。界面按变化内容刷新，不反复创建控件。开启新批次先新建并保存 CSV，再检查固件、准备授权并启动扫描；取消或保存失败不会开始烧录，已有 CSV 不会覆盖。

## 0.5.1 界面调整

批次统计、CSV 和设备队列分区显示；双芯固件继续左右排列，公共烧录模式、并发板数和产测设置独立显示。表格增加留白，MAC、进度、产测、云端与整板结果分层展示；长文本可悬停或打开详情查看。所有原有操作与烧录流程保留。

## 使用

1. 选择 ESP32 完整 16 MB BIN、RingHi ML307H PKG、备份目录和官方授权项目。
2. 开启新批次，先新建并保存 CSV 文件；保存成功并完成固件与公共授权检查后才接收设备。
3. 自动按同一板载 Hub 配对，两颗芯片分别在线程中执行。成功行留在接入表，拔出后归档；重插新建任务。
4. ML307 默认自动激活。产测通过、云端登记和最终报告上传全部确认后才显示整板成功。
5. 暂停接收不打断正在执行的任务；退出时可取消，确认退出后停止任务并保存 CSV。

程序复用 `%APPDATA%/ringhi-flasher/native-preview` 和旧 DPAPI 账号。账号在本机解密，不嵌入包、不写日志。旧 CSV 和原备份保留。
下载模式恢复需唯一匹配原记录、同一 ESP MAC、原固件，以及存在时匹配芯片 UID；中断写入只使用完整性校验通过的原始备份。激活结果未知时不重复领取激活码。

## 开发与验证

Python 3.13，Windows x64；安装 `requirements-build.txt`，运行 `python -m pytest tests -q`。
`python main.py --ui-test <独立目录>` 进行明确隔离的软件界面、队列、CSV 与关闭验证，不扫描或操作硬件。
`build.ps1` 先测试再生成 onedir 应用；用户无需安装 Python。

本包无代码签名，不宣称通过 Smart App Control / SmartScreen 信任验证。
公开更新只接受同一 GitHub 仓库、同一版本的 `RingHi-Setup-x.y.z-win-x64.exe` + `SHA256SUMS.txt`；兼容 ZIP 供 0.5.5 及更早 Python 客户端升级。

## 许可与第三方组件

Qt / PySide6 按 LGPLv3 使用，动态链接随包分发；Qt 库位于 `_internal/PySide6`，可以按 LGPL 条款替换兼容动态库。
Qt 源码与条款：https://code.qt.io/cgit/pyside/pyside-setup.git/ ，https://www.qt.io/licensing/open-source-lgpl-obligations
运行依赖版本由 `DEPENDENCIES.txt` 记录；随包保留 Qt、Python、pySerial、Requests、cryptography、psutil 的上游许可文件。
官方 esptool 可执行程序、对应源码压缩包及 GPLv2 许可随 Tools 目录一起保留。
