## 实现
- 健康、响应已完整消费的官方 HTTPS Session 可在不同任务间独占借用，最多保留 8 条空闲连接。失败或未完整读取的响应连接丢弃；不并发共用 requests Session，不保存跨任务 Cookie。始终直连，保持 TLS 验证和已有设备请求重放边界。
